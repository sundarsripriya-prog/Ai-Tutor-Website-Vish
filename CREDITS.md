## How this file is kept honest

A row goes in this table at the moment the borrowed code is pasted, not later.
The same code carries an inline marker at its location in the source file:

```jsx
/* === BORROWED CODE START ===================================
   Component: <name>
   From:      <source>
   URL:       <url>
   Retrieved: <YYYY-MM-DD>
   Changes:   <what I changed and why>
   =========================================================== */

/* === BORROWED CODE END ===================================== */
```

For a single borrowed line rather than a block, one comment above it is enough.

Rule of thumb for what needs marking: if I could not rewrite it from memory, it
gets marked. Copying four lines from a documentation page counts. Reading a
documentation page and then writing my own version does not.
